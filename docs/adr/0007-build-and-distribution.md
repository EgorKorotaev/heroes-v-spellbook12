# ADR 0007 — Портативная сборка и частный выпуск

Статус: принято. Дата: 2026-11-07.

## Решение

Исходный репозиторий содержит код, документацию, числовые fixtures и небольшие
иллюстрации. Игровые EXE/DLL, полные архивы, карты, профили и диагностические
папки разработки в Git не включаются. Исследование кампаний не является частью
этого репозитория.

Сборщик принимает `--game-root`, `--edition`, `--output`. Он читает собственную
поддерживаемую установку разработчика, не запускает игру и не записывает в неё.
Старый лабораторный `build_probe.py` совмещал генерацию с развёртыванием
тестовой копии и работой с EXE. Для выпуска эти обязанности разделены; не
возвращать старый deploy-путь в новый builder.

Вывод внутрь игры и перезапись готовой сборки запрещены. Сначала создаётся
временная сборка, затем проверяются ZIP и байты каждого участника.

Universe-пакет включает два исходных текстовых шаблона книги из его локальных
архивов. 5.5-пакет не подменяет их шаблонами Universe. Переводы остальных
ресурсов и «хвосты» русификации остаются отдельной разработкой.

ZIP имеет фиксированные порядок и timestamps. В PAK дата участников
`2107-12-31 23:59:58` обеспечивает ресурсный overlay; её наличие само по себе
не было причиной стартового сбоя в контрольных запусках. PS-скрипты выдаются
как UTF-8 с BOM и CRLF, CMD как ASCII/CRLF. Нормализация происходит в builder,
чтобы checkout с правилами `.gitattributes` не менял готовый пакет.

Проверка повторяемости: собрать из рабочего дерева и из чистого клона тем же
окружением и сравнить ZIP побайтно. Это проверка конкретного toolchain,
не обещание одинакового Deflate на любой версии Python/zlib.

## Лицензия и передача

Пользователь явно выбрал MIT для нашего кода. Она не перелицензирует игровые
модели, текстуры, шрифты и тексты. Происхождение производных ресурсов указано
в `NOTICES.txt`; оригинальные полные игровые файлы не распространяются.

Первый адресат — один игрок и его AI. Поэтому готовятся два player ZIP,
source ZIP, история локального Git и контрольные суммы. Публикация на удалённый
GitHub/релиз — отдельный шаг после выбора репозитория и готового результата.
Коммиты агента обозначают Codex как author и committer, не выдаются за Егора.

Готовый ресурсный PAK без launcher не включает runtime-часть. Запуск напрямую
через EXE или H5Lobby не равен запуску мода. Интеграция с lobby и multiplayer
не заявляются только на основании успешной одиночной игры.

## Оформление и обратная связь — beta.2

Следующий частный пакет получает отдельную версию `0.1.0-beta.2`. Предыдущий
тег beta.1 остаётся на прежнем коммите. Callback, native manifest, все члены
ресурсного PAK и Windows-скрипты сохраняются побайтно; обновляются документы,
метаданные выпуска и список включённых документов (`FEEDBACK.txt`).

README явно показывает точные поддержанные сборки, непроверенную сеть,
неинтегрированный запуск через H5Lobby и условия «как есть» из MIT.
Отказ от ответственности ограничен применимым законом; он не выдаётся за
гарантию отсутствия любых юридических требований. Полный текст MIT сохранён.

Шильдики — наши статические SVG без внешнего сервиса. Не изображать их как
действующий CI или число сетевых проверок. Сравнение «без / с» должно быть
снято в реальной игре: одна редакция, один сценарий, герой и размер окна.
Для «без» отключаются оба слоя мода и сохраняется родная камера.
Параметры/хеши снимков фиксируются в `release/presentation.json`; тестовая
копия после съёмки восстанавливается. Не заменять игровые кадры макетами.

На GitHub используются две формы в `.github/ISSUE_TEMPLATE/` и шаблон PR.
Метки/назначения не зависят от ещё не созданного репозитория. Формы доступны
после публикации в default branch репозитория с включёнными Issues; текущее
наличие файлов не означает работающий внешний tracker. Основание формата:
[GitHub Docs](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/configuring-issue-templates-for-your-repository).

Для личного ZIP оба player-пакета содержат двуязычный `FEEDBACK.txt`.
`CONTRIBUTING.md` описывает проверку, воспроизведение, идеи и изменение кода.
Не требовать знания хеша как условия сообщения о баге; достаточно известных
сведений с последующим уточнением. Игровые бинарники и личные профили не
принимаются как публичные вложения.

## Публичный репозиторий

После подготовки частного кандидата пользователь явно выбрал публичную
видимость и подтвердил аккаунт `EgorKorotaev`. Адрес проекта:
`https://github.com/EgorKorotaev/heroes-v-spellbook12`.
Исходники и существующие теги отправляются без изменения истории и меток.
Публикуется предварительный выпуск beta.2 с проверенными архивами.

Документы main получают реальные ссылки; уже собранные пакеты и тег beta.2
сохраняются. Для повторения их хешей checkout делается на `v0.1.0-beta.2`,
не на более поздний main. Результаты `release/reproducibility.json` относятся
к этому снимку. Файлы из рабочих игровых копий для публикации не добавляются.
