# Архитектурные решения Spellbook12

Эти записи объясняют устройство мода и сохраняют причины решений и неудачных
проб. Они относятся к книге заклинаний; исследование API и перенос кампаний
живут в другом проекте. Состояние игровых проверок смотри в `VALIDATION.txt`
в корне: принятое решение само по себе не означает проверку каждого EXE.

| ADR | Решение |
| --- | --- |
| [0001](0001-scope-and-engines.md) | Границы мода и точные профили движков |
| [0002](0002-layout-and-text.md) | Размеры книги, сетка, миниатюры и перенос текста |
| [0003](0003-paper-and-animation.md) | Общая сетка бумаги и заклинаний, перекрытие при перевороте |
| [0004](0004-native-interactions.md) | Выбор, подсветка, кнопки и подсказки |
| [0005](0005-runtime-launch.md) | Изменения только в памяти и порядок запуска |
| [0006](0006-installation-ownership.md) | Владение файлами, установка и удаление |
| [0007](0007-build-and-distribution.md) | Сборка, исходники, лицензия и передача |
| [0008](0008-validation.md) | Уровни доказательств и изолированные игровые проверки |

Для изменения решения добавь новый ADR либо явно пометь старое решение как
заменённое и дай ссылку на преемника. Не превращай удачный единичный кадр,
совпавший хеш или предположение из раздела о неудачных пробах в доказательство.

Дата записей: 2026-11-07. Инициатор и проверка в игре — Егор;
реализация и документирование — Codex совместно с Егором.
