# ADR 0004 — Геометрия выбора, подсветка и подсказки

Статус: принято. Дата: 2026-11-07.

## Контекст

После расширения книги широкие поверхности заклинаний перекрывали кнопки.
Были промахи при перелистывании, расхождения действия и подсветки, а текстовые
подсказки появлялись в разных углах окна. Пользователь просил родное поведение.

## Решение

Оставить родные кнопки, selector и dispatch действий. Исправлять геометрию,
по которой движок выбирает part, вместо ручной подмены выбранного действия.

- Part `15` — вперёд, `16` — назад, `17` — закрыть, `18` — мана.
- Вперёд и закрытие проецируются к камере на 2.5% вдоль собственных лучей.
  Такая гомотетия сохраняет экранную форму, UV и skin data, но выводит реальные
  треугольники кнопки перед расширенными spell overlays.
- У заклинаний сужены только пустые горизонтальные поля выбора. Отрисовка
  названия шире активной области; текст может занимать место вне области клика.
- Фильтр применяется только к spell parts. Для стрелок, вкладок, закрытия
  и отклонённых попаданий сохраняется родная обработка и очистка результата.
- Очистка hover проходит все 12 outliner-записей, не прежние шесть.

Границы X попадания относительно начала луча камеры:

| Столбец | Нижняя | Верхняя |
| --- | --- | --- |
| Левый лист, первый | -3.944406 | -2.519531 |
| Левый лист, второй | -2.183422 | -0.752115 |
| Правый лист, первый | 0.754845 | 2.171325 |
| Правый лист, второй | 2.510779 | 3.940645 |

Это параметры конкретной согласованной геометрии, не универсальные координаты
для любого размера книги. При изменении камеры или сетки их надо перепроверить.

## Два пути подсказок

Кнопки используют родную проекцию bounds модели. Её render-пиксели переводятся
в UI units с размерами render/UI и UI offset; extents не получают offset.

Описания заклинаний используют отдельный родной путь icon presets. Все 12
прямоугольников вычисляются из UV и фиксированных поверхностей
`10,26,11,27,12,28,7,35,8,36,9,37`. Фиксированные поверхности дают устойчивые
bounds, когда анимированный аналог временно скрыт.

У 5.5 другая проекция UI: фиксированная система 1024×768. Нельзя копировать
Universe-формулу и менять только абсолютные адреса. В 5.5 также обходится
проверка шести устаревших 2D-прямоугольников, сохраняя mesh/ray-фильтр.

## Полученные шишки

Сдвинуть только область действия, оставив подсветку, недостаточно. Расширенная
буква/подпись тоже не должна расширять клик до края страницы. Прямоугольник
подсказки кнопки нельзя использовать как прямоугольник описания заклинания.

Не было отдельного решения переделывать анимацию крестика: сначала требовалось
совместить его реальные выбор, действие и подсказку с изображением.

## Проверка и код

Проверять края и центр обеих стрелок и крестика, соседние пустые поля,
переключение школ, все 12 позиций, отсутствие случайного каста при перелистывании.
Проверять подсказку при наведении после переворота, а не только на первой странице.
