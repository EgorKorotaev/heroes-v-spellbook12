## Как получено сравнение «без / с»

Дата: 2026-11-07. Два свежих запуска отдельной Universe-лаборатории, один
неизменный диагностический сценарий и Зехир с выданными для проверки заклинаниями.
Это иллюстрация интерфейса, не пример обычного состава героя в кампании.

В кадре «без» отключены оба слоя Spellbook12: ресурсный PAK отсутствует,
launcher не применяет никаких изменений в памяти. Сохранена исходная камера
книги Universe. В кадре «с» включены принятый 1280-байтовый callback и финальный
PAK с согласованной сеткой переворачиваемой бумаги. Они совпадают с beta.1;
beta.2 меняет оформление поставки и документацию.

Окно игры в обоих случаях — 1280×960. Foreground-захват уменьшен до 960×720,
затем одинаково обрезан по прямоугольнику `(0, 75, 960, 595)` до 960×520.
Содержимое книги, текст и значки не ретушировались; коллаж внутри кадров
не использовался. Оба кадра просмотрены. Проверка состояния до/после,
SHA-256 и параметры захвата — в [presentation.json](../../release/presentation.json).

После съёмки лаборатория остановлена, два временно изменённых файла
восстановлены с проверкой хешей. Рабочие игровые копии не использовались
как место установки. Снимки не подтверждают сетевую совместимость,
прохождение кампаний или поддержку других EXE.
